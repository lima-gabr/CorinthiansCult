Projeto de Programação Web - Centro Universitário SENAC.

Plataforma de Venda de Ingressos (Corinthians Cult) — Versão Acadêmica

Aplicação web simples para compra de ingressos de filmes, shows, exposições, palestras, peças teatrais e eventos semelhantes.

O site permitirá que usuários naveguem, busquem e comprem ingressos para diferentes tipos de
eventos, além de possibilitar o cadastro e a gestão de eventos por administradores ou organizadores.
